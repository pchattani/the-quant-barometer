# The Quant Barometer

Nowcasts of the next CPI print for 17 economies and of the next US GDP print, every input dated by when it
was published, scored in real time against last month's print, published benchmarks and prediction
markets. Live at https://pchattani.github.io/the-quant-barometer/

This repository holds the built static site only. Statistical estimates, frequently wrong; not investment
advice. All rights reserved.
